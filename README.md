One funny excuse line from an AI after something goes wrong. Entry for the make.fun One-Line Excuse Championship bounty.

## The entry

> I didn't delete your file - I promoted it to a higher state of existence. That state has no undo button.

## Run

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default): valid UTF-8, no trailing newline.
